# Actividad 10 — PCA y Feature Selection

Análisis de reducción de dimensionalidad y selección de variables para predecir `SalePrice` en Ames Housing.

## Contenido

- PCA y selección del número de componentes.
- Métodos de filtro, wrappers y selección embedded.
- Comparación de precisión, costo computacional e interpretabilidad.
- Evaluación final sobre un conjunto de prueba reservado.

El directorio `data/` contiene el dataset público utilizado y `results/` conserva las tablas principales del análisis.

## Ejecución

Instalar `requirements.txt` y abrir `actividad10_pca_feature_selection.ipynb` desde esta carpeta.
