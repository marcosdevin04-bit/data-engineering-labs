# Actividad 11 — Temporal Feature Engineering

Construcción y evaluación de variables temporales para predecir si un cliente realizará otra compra durante los 30 días posteriores a una factura.

## Contenido

- Variables de calendario, recencia, frecuencia e historial.
- Prevención de fugas de información temporal.
- Validación blocked, walk-forward y purged forward con embargo.
- Transferencia del enfoque desde Online Retail hacia Olist.
- Importancia de variables y predicciones sobre test.

## Datos

Se incluyen los datasets públicos utilizados para que el análisis sea reproducible:

- Online Retail: `data/online_retail/OnlineRetail.csv`.
- Olist: clientes, pedidos e ítems de pedidos dentro de `data/olist/`.

Fuentes: [Online Retail](https://www.kaggle.com/datasets/vijayuv/onlineretail) y [Brazilian E-Commerce by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce).

## Ejecución

Instalar `requirements.txt` y abrir `actividad11_temporal_feature_engineering.ipynb` desde esta carpeta.
